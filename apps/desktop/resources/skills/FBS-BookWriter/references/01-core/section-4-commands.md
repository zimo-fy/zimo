## 基础指令（15条）

### 写作类

| 用户说 | 执行 |
|--------|------|
| "写"/"成文" | 生成当前章节 |
| "下一章" | 启动下一章流水线 |
| "续写" | 继续当前内容写作 |

### 搜索类

| 用户说 | 执行 |
|--------|------|
| "搜一下"/"验证" | 联网搜索并报告 |
| "竞品" | 重新竞品扫描 |
| "保鲜表" | 输出数据保鲜表 |

### 构建类

| 用户说 | 执行 |
|--------|------|
| "构建" | 排版构建（阶段4） |
| "导出" | 导出打包当前项目 |
| "封面" | 重新生成/调整封面 |
| "加图" | 追加/修改插图标记 |

### 查看类

| 用户说 | 执行 |
|--------|------|
| "自检" | 输出详细质量报告 |
| "图表" | 查看/修改当前章Mermaid图表 |
| "视觉清单" | 输出全书视觉资产清单 |
| "风格" | 显示/修改风格档案 |
| "策略" | 显示/切换策略组合 |
| "日志" | 显示当前运行日志 |
| "加载日志" | 加载上次运行日志 |
| "推荐" | 使用默认策略（标准×标准协同） |

## 新手引导（19条）

### 模式切换类

| 用户说 | 执行 |
|--------|------|
| "切换模式"/"换模式" | 打开模式切换界面（新手/专家） |
| "新手模式" | 切换到新手模式（引导式体验） |
| "专家模式" | 切换到专家模式（完整功能） |
| "当前模式" | 显示当前使用模式 |

### 偏好管理类

| 用户说 | 执行 |
|--------|------|
| "偏好设置"/"我的偏好" | 打开偏好设置面板 |
| "保存模板" | 保存当前配置为模板 |
| "加载模板" | 加载已保存的模板 |
| "删除模板" | 删除指定的模板 |
| "模板列表" | 显示所有可用模板 |

### 资产管理类

| 用户说 | 执行 |
|--------|------|
| "我的资产" | 打开资产管理面板 |
| "交互资产" | 筛选交互资产 |
| "产物资产" | 筛选产物资产 |
| "模板资产" | 筛选模板资产 |
| "自动化规则" | 筛选自动化规则 |
| "清理资产" | 打开批量清理界面 |
| "标注参考" | 将资产标注为参考素材 |

### 自动化类

| 用户说 | 执行 |
|--------|------|
| "重新引导"/"重新开始" | 重新开始新手引导流程 |
| "跳过引导" | 跳过新手引导，直接进入 |
