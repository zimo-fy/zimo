# 历史回复模型名跟随输入区选择

## 症状与影响

助手气泡用量行的模型显示名会随输入区当前模型一起变化。已经生成的历史回复被改写成新选择的模型，无法看出当时实际用的模型。

## 证据与复现

- 用量组件接收会话级当前模型显示名，并套用到每一条助手气泡；
- 切换输入区模型后，历史气泡名称同步更新，无需重新生成。

## 根因

生成结果没有按消息保存模型显示名。Renderer 用会话当前目录/本地模型名填充所有历史回复。

## 修复

`0043` 为 `messages` 增加可选 `model_display_name`。发送和重新生成时把当时的目录或本地模型显示名写入助手消息；切换会话 `modelId` 不回写已有消息。气泡只读取该字段；升级前为 NULL 的消息省略模型名。

## 回归覆盖

- ConversationService：发送后切换会话模型，旧助手消息仍为生成时名称；
- MessageBubble：有快照则展示名称，无快照则省略；
- Desktop migration 序列包含版本 43。

## 剩余风险

已运行的桌面进程必须完整重启以应用 migration。升级前的历史回复不会回填名称。重新生成的乐观占位在会话详情刷新前可能暂时没有名称。
