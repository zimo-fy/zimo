# Conversation Experience V0

状态：已实现  
日期：2026-09-08

## 目标

会话页采用桌面 AI 工具常见的“全局任务侧栏 + 底部指挥台”结构：消息区域专注阅读，输入框下方只常驻能力入口、已选摘要、模型和发送操作。Agent、Skills、知识库、Workflow 与 MCP Tool 收纳在“+”弹层中。布局参考 WorkBuddy 的输入区信息架构；选择能力即写入当前会话授权。

参考：

- [WorkBuddy 创建与发送任务](https://workbuddy.tangshuang.net/full-tutorial/3.2%20%E5%88%9B%E5%BB%BA%E4%B8%8E%E5%8F%91%E9%80%81%E4%BB%BB%E5%8A%A1)
- [WorkBuddy 官网](https://www.workbuddy.ai/)

## 输入区

- textarea 根据内容在 72–180px 范围内自动增高，超过上限后内部滚动；
- Enter 发送，Shift+Enter 换行，中文输入法组合态不会误发送；
- 底部工具栏以“+”作为统一能力入口，点击后分组选择 Agent、查看 Skills、选择知识库或查看 Workflow 状态；
- 已选 Agent、随 Agent 挂载的 Skills 和知识库以 11px 紧凑摘要展示，长名称截断，Skills 超过两个后显示剩余数量；
- 模型和发送操作保持常驻，运行期间统一禁用配置切换；
- 发送、停止和重新生成使用紧凑操作区，错误和 Agent 确认保持在输入内容附近；
- Agent 可能覆盖会话模型时在模型选项中明确提示。

## 任务与能力边界

现有 Conversation 直接作为全局“任务”显示在主菜单下方，按最近活动时间排序。任务区独立滚动，以“标题 + 时间”单行展示，hover 后显示管理菜单，支持新建、打开、重命名和确认删除；打开任务仍使用同一个聊天页和持久化能力状态。主导航移除概览入口，登录后直接进入任务工作区。

instruction Skill 必须先安装。会话可直接多选 Skill，也会合并所选 Agent 自带的 Skill；Agent、知识库、Workflow 与逐项 MCP Tool 同样通过严格会话能力契约持久化。切换任务或重启后恢复，不再要求重复确认 Agent。

选择 Workflow 后发送会执行其保存的 DAG 并把结果写回当前任务。MCP 与脚本 Skill 调用仍经过 Application 的授权集合、参数、超时、取消、输出和审计边界。

## 智能滚动

- 打开或切换会话时立即定位最新消息；
- 用户发送新消息时恢复贴底；
- 用户仍在底部 96px 范围内时，保留 Chromium 原生底部滚动锚点，并在消息内容或可视区域高度变化时通过 `ResizeObserver` 按布局变化即时校正底部位置；这覆盖首条回复从无滚动条增长到出现滚动条的场景。校正不使用平滑动画，也不在每个文本事件中写入滚动位置；
- 用户主动上翻超过阈值后暂停自动滚动，避免抢夺阅读位置；
- 暂停期间显示“回到最新”按钮，点击后平滑滚动并恢复自动跟随；
- 滚动条预留稳定 gutter，避免滚动条出现或尺寸变化引起横向布局跳动。

## 回复用量

用户气泡右下方常显发送时刻，助手气泡左下方常显开始/完成时刻；两侧气泡采用 14px 圆角和紧凑垂直内边距，用户消息右上角、助手回复左上角为直角，不使用突出气泡轮廓的三角尾角。用户复制按钮仍仅在悬停或键盘聚焦时出现，时间不随其隐藏。助手正在输出时先显示创建时刻，终态显示完成、停止或失败时刻。

已完成、已停止或失败的助手气泡内部底部展示本轮发送合计的 token 消耗和该条回复生成时的模型显示名；时间只在气泡下方展示一次。合计包含主回复/Tool 轮、Router 分类和首轮标题；用户停止后会继续读取当前模型流以补记 usage。提供商未返回时省略消耗，不伪造 0。输入区当前模型只影响后续发送；切换后不得改写历史气泡上的模型名。升级前未快照的消息省略模型名。每条终态助手回复的用量右侧提供重新生成，提示后续内容会被覆盖。详见 [助手回复用量展示](assistant-reply-usage.md)。

## 思考时间与工具步骤

助手气泡上方展示本轮墙钟耗时（进行中 `思考中 {n}s`，完成后 `已完成 {n}s`，停止或失败 `已停止 {n}s`）。思考中且尚无回复正文、附件或资料引用时只显示耗时与工具步骤，不渲染空气泡；出现回复内容后再显示气泡。有工具步骤时，进行中展开显示，完成/停止/失败后默认折叠，点击耗时标题可展开。工作目录读取显示 `读取 notes.md`，完成后追加 `已读取 notes.md`；绝对路径只保留文件名。不展示深度思考正文、工具输出或 Router/标题/Workflow 内部步骤。详见 [助手回复思考时间与工具步骤](assistant-reply-timeline.md)。
