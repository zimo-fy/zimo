# Automation 本地调度

## 用户能力

- Automation 可选择模型，并绑定一个 Agent 或 Workflow、多个 Skill、知识库和逐项 MCP Tool；这些配置与普通会话使用相同能力契约。
- 支持单次、按分钟间隔、每天和每周计划；固定间隔从保存或重新启用时开始计时，不设置首次执行时间。
- 可设置每天的开始与结束时刻；当前时刻不在范围内时不执行。
- 支持启停、立即运行、查看最近运行结果与删除。
- 列表页说明文字后提供“快捷创建打招呼自动化任务”链接：打开新建表单并预填招聘 Prompt，标题下直接接正文、不插入空行，用户可继续修改岗位、平台和人数；指令输入框随内容自动增高。此操作不会自动保存、运行、安装或绑定 Skill，也不会改变执行计划与权限。浏览器已是内建能力，但仍需安装并绑定招聘 Skill、预先在 Zimo Profile 登录各平台，且使用支持 Tool Calling 的模型；登录失效或验证码会使后台运行停下待人工处理。
- 新建和编辑表单中的“执行能力”默认折叠，用户可按需展开；折叠标题展示已绑定的 Agent、Workflow、Skill、知识库及 MCP Tool 数量。折叠只影响展示，不改变已有绑定和保存行为。

## 执行流程

1. 保存 Automation 时创建或更新一个专用会话，并把能力绑定写入该会话。
2. Main 进程调度器领取到期任务；数据库保证同一任务不会重叠运行。
3. Application 通过 ConversationService 向专用会话发送用户配置的指令。
4. 运行终态写入 `automation_runs`，列表显示最近状态和下次执行时间。
5. Automation 存在期间，专用会话不能从普通任务列表单独删除。删除 Automation 时，已产生消息的专用会话作为历史任务保留，并可从任务列表单独删除；从未产生消息的空会话随配置删除。退出或切换账号时取消当前账号的运行。

专用会话的首轮消息建立后会出现在左侧任务列表；后续手动或定时运行继续更新同一会话，不创建新任务。运行开始、结束及删除配置后的轻量通知会让 Renderer 重新读取现有任务列表；删除配置不会使已有历史任务从侧栏消失。窗口未打开时不缓存通知，打开时依靠初始列表读取恢复。

## 时间语义

- 每天、每周和执行时间范围均使用设备本地时区；用户修改系统时区后，后续计算会采用新时区。
- 时间范围两端均包含；默认 `00:00`–`23:59`。开始时间晚于结束时间时表示跨午夜，例如 `22:00`–`06:00`。
- 固定间隔在范围外暂停，到下一个范围开始时刻执行，并从该次执行重新计算间隔；每天、每周或单次执行时刻与范围冲突时拒绝保存。
- 应用关闭期间不运行。再次启动后，到期任务最多补执行一次，然后直接计算未来的下一次时间。
- 最小间隔为 5 分钟，最大间隔为 30 天。

## 安全与失败

Automation、专用会话和运行记录均按登录账号隔离。入站 IPC 使用严格 Schema；普通日志不记录指令正文、模型输出或 Tool 参数。模型、能力或外部服务失败会落为失败运行，不伪造成功；应用崩溃遗留的运行在下次启动时修复为失败。

共享浏览器 Profile 的模型运行互斥：一个任务首次调用浏览器 Tool 后持有至该 Tool Loop 结束，其他同时使用浏览器的任务收到 `BROWSER_RUN_BUSY`。这不阻止用户手动操作已打开的可见浏览器；同时编辑同一页面仍可能使模型快照失效。
