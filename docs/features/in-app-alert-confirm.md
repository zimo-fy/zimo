# 应用内提示与确认对话框

## 用户能力

删除、卸载、解绑等危险操作，以及新建任务失败提示，使用应用内对话框，不再调用浏览器原生 `alert` / `confirm`。

- 提示：标题「提示」，仅「确定」；
- 确认：标题「请确认」，「取消」与「确定」；Escape 视为取消；
- 打开后焦点进入对话框，Tab 在按钮间循环；关闭后若后续流程没有立刻聚焦新输入，则焦点回到触发控件。

## 范围

覆盖原先全部原生弹窗调用：新建任务失败、删除任务、删除记忆、解绑 MCP、解绑通信渠道、删除自动化、卸载 Skill、删除知识库文档、删除/卸载 Agent 等原型项、退出未保存的工作流编辑器。

系统文件选择/另存为和文档预览层不在本能力内。

## 动机

Windows 上 Electron 调用原生 `alert`/`confirm` 后，操作系统焦点可能离开 BrowserWindow，随后无法点选或键入会话输入框。应用内层叠对话框始终留在 Chromium 内。

## 验证

- `@zimo/ui` 组件测试覆盖提示关闭、确认确定/Escape 取消，以及取消后焦点回到触发按钮；
- 任务导航组件测试在 `AppDialogProvider` 下运行；
- Electron E2E 点击应用内「确定」，不再监听 Playwright `dialog` 事件。
