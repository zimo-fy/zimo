# 默认回复语言

## 用户行为

Zimo 的普通会话、Agent、直接绑定 Skill、模型 Tool Calling 和 Workflow Agent 默认使用简体中文生成面向用户的自然语言回复。英文 Agent Prompt、Skill 指令、Tool 返回值或知识库资料不会自动把最终回答切换为英文。

代码、命令、文件路径、API 标识、专有名词及用户要求保留的原文可以维持原语言。用户在当前请求中明确要求翻译或使用其他语言时，模型可以按该请求切换；后续没有明确语言要求的请求恢复简体中文默认值。

任务标题生成原本已经独立要求中文。Intent Router 使用结构化输出，不属于自然语言回答，不受该策略改变。

## 实现边界

语言策略由 Application 层编译进模型 System Prompt，不写入或修改已安装 Agent、Skill 和历史消息，也不依赖具体模型厂商。带 Agent 或 Skill 的请求把策略附加在能力指令末尾；没有绑定能力的普通会话也会获得独立语言 System Prompt。Workflow 复用相同的 Agent Prompt 编译，因此 Tool 执行前后的模型轮次保持同一语言规则。

该策略是模型指令约束，不是对生成文本进行机器翻译或字符级拦截。模型仍可能偶发不遵循指令；若后续需要绝对禁止非中文输出，应另行设计输出检测、重试和流式展示回滚，不能在已展示后静默替换内容。

## 验证

- 普通会话即使用户输入英文，也包含简体中文默认回复规则；
- 英文 Agent 和英文 Skill 指令保留原文，同时在同一 System Prompt 中追加中文规则；
- 直接绑定 Skill 和 Workflow Agent 使用相同规则；
- 用户明确要求其他语言的例外写入规则，避免破坏翻译和多语言任务。
