# Workflow Editor V0

## 目标

本增量把 Phase 3 的工作流画布原型升级为本地持久化的产品编辑器。交互参考 FastGPT 的工作流编排心智：独立编辑空间、节点库、无限画布、节点配置侧栏，以及清晰的输入、输出和连接端口；视觉与数据结构继续使用 Zimo 自有实现。

## 编辑流程

1. 在工作流详情中进入独立编辑器；
2. 从左侧节点库搜索并添加节点；
3. 在中央画布拖拽节点，从输入/输出端口建立连接；
4. 选择节点后，在右侧配置名称、引用对象、输入输出或执行说明；
5. 使用工具栏或 `Command/Ctrl + S` 保存；使用 `Command/Ctrl + Z`、`Command/Ctrl + Y` 撤销和重做；
6. 保存前由 Application 校验结构和引用，成功后写入 SQLite；
7. 点击“测试”输入问题，查看节点运行状态、耗时、跳过原因和最终输出。

画布提供缩放、平移、网格吸附、小地图和选中删除。开始节点唯一且不可删除；至少保留一个结束节点。

## 节点与配置

- 开始：声明入口输出变量；
- Agent：选择已启用 Agent，并保存节点补充指令；
- Skill：选择已启用 instruction Skill；
- 知识检索：选择已启用知识库并设置 Top K；
- Tool：选择可信注册表中的能力；首个只读 Tool 需要配置允许检索的知识库；
- 条件：保存受限条件表达式文本；
- 人工确认：保存用户确认说明；
- 结束：声明最终输入变量。

`WorkflowDefinition` 保存 Zimo 自有节点、坐标、配置、边和端口 ID。React Flow 对象只存在于 Renderer mapper 中，不进入领域层或数据库。

## 校验与安全边界

Application 保存时校验：

- 节点 ID 和边 ID 唯一；
- 恰好一个开始节点，至少一个结束节点；
- 边的端点存在，禁止自连、指向开始节点或从结束节点发出；
- 当前节点集合必须为无环图；
- Agent 与知识库引用必须存在且已启用。

安全运行时现已支持开始、知识检索、instruction Skill、受控只读 Tool、GitHub 仓库搜索、Agent 和结束节点。条件与人工确认仍在运行前拒绝；不编译 LangGraph，也不开放 Shell、其他远程 MCP、Plugin、写入/删除 Tool 或任意代码执行。FastGPT 仅作为交互参考，不复制其运行时或受其许可约束的源代码。

## 持久化

`0008_workflow_definitions.sql` 增加独立 `workflow_definitions` 表。工作流列表、详情、节点配置和布局在应用重启后恢复；内置示例只初始化一次。

## 验证

- Contract：节点配置和连接端口使用 strict Schema；
- Application：非法边、循环、开始/结束结构和引用状态；
- SQLite：节点配置与端口跨重启恢复；
- Electron E2E：打开编辑器、添加知识检索节点、绑定知识库、保存并重启恢复；
- Runtime：拓扑执行、未连接节点跳过、不支持节点预检和知识 Top K；
- 安全回归：Renderer 仍不获得 Node、密钥或数据库能力。
