# 云端知识库目录与同步

状态：知识库页面已移除「账号云端知识库」区域。进入知识库页不再请求云端目录，也不再自动导入或在卡片上提供云端更新。

## 行为

原先在桌面应用 **工具 → 知识库** 列表页顶部，登录后自动请求账号云端目录：

- `GET ai/knowledge/directory/tree-with-documents`（相对 `resolveAuthBaseUrl` 根地址，Bearer 与 Skill/模型目录相同）；
- 展示目录树、各目录下文档清单，以及 `uncategorizedDocuments`；
- 进入列表页或点击「刷新」时，**自动**为尚未绑定的云端目录执行导入（新建本地库、下载并 `importFiles`、写入 `knowledge_cloud_links`，成功后 **自动启用**）；云端卡片仅浏览目录树，不提供手动导入按钮。
- 已同步的本地知识库（标签 `cloud-dir:{id}`）在列表卡片操作栏提供 **更新**（位于启用/禁用按钮前），按 checksum 增量同步。

## 安全

Renderer 不直接访问云端 URL；目录 IPC 视图不含 OSS 地址。文件下载仅在 Main 完成（HTTPS 公网校验、大小上限）。日志不记录文件正文与密钥。

## 验收

1. 进入知识库页只看到本机知识库列表，没有「账号云端知识库」标题，也不出现云端「更新」按钮；
2. 本地新建、导入和检索仍可用。
